# Development Prerequisites

Run:

```bash
npm run check:prereqs
```

Required:

- Git
- Node.js 22.x
- npm 10+
- VS Code
- PostgreSQL client (`psql`)
- Noir Wallet testnet browser extension
- exact ZSA test-network tooling selected during the hands-on ZSA POC

We intentionally do not invent or pin a ZSA CLI here. Once proven, record the exact repository/tag/commit, install command, network endpoint, issuer/recipient format, and verification commands.
