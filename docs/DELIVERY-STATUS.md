## Critical limitations

The original ZSA path cannot honestly be delivered as a working native mint by filling environment values. No verified Noir ZSA recipient-control interface exists in the supplied project. A private server issuing to itself is not customer ownership. Ordinary Zcash RPC cannot decrypt shielded receipts without appropriate viewing capability. This build intentionally has no public endpoint to mark payment confirmed or assets minted.

The previously shared issuer seed is exposed; use only for disposable tests and never production. This package does not include that seed, wallet database or git history.
